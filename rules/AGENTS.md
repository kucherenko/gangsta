# Gangsta bootstrap (Antigravity)

This rule is loaded on every turn when the Gangsta plugin is enabled. It inlines the Antigravity tool mapping and the `using-gangsta` skill so the tool names, hierarchy and invocation rules are always in context. The mapping comes first so it survives if the rule ever hits Antigravity's 24,000-byte per-rule cap.
